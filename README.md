# Colis — Сетевой 3D-симулятор расстановки товаров (Three.js + Rapier3D)

Production-ready многопользовательский симулятор управления и раскладки товаров в магазине в изометрической перспективе.

## 🌟 Ключевые архитектурные решения

1. **Физический движок — [Rapier3D](https://rapier.rs/) (Rust Wasm SIMD):**
   - Используется `@dimforge/rapier3d-compat`.
   - Кроссплатформенная IEEE-754 детерминированность расчётов.
   - Встроенный `KinematicCharacterController` для передвижения персонажа со сглаживанием ступеней, коллизиями со стенами и стеллажами.
   - Одинаково запускается как в браузере (клиент), так и на Node.js/Bun (сервер).

2. **Рендеринг тысяч товаров через `InstancedMesh` (Zero GPU Draw Call Overhead):**
   - **Dual-State механика предметов**: динамическая физика коробок и товаров работает только при перемещении/падении.
   - При выставлении на полку товар переходит в состояние слота, а Three.js объединяет сотни и тысячи банок/коробок в **единый `THREE.InstancedMesh`** на каждый тип товара.
   - 10 000 товаров на стеллажах отрисовываются всего за 5–6 draw calls с частотой 60–120 FPS.

3. **Сетевой кооператив (Server-Authoritative Co-op):**
   - Высокопроизводительный сервер на Node.js + WebSocket с фиксированным тикрейтом (25 Hz).
   - Валидация действий на сервере: предотвращение читерства, проверки дистанции (`MAX_INTERACTION_DISTANCE`), предотвращение race condition (когда двое одновременно пытаются взять одну коробку).
   - Интерполяция снапшотов для плавного движения удалённых игроков.
   - Система сессионных комнат/магазинов (подключение к комнатам по коду).

4. **Изометрическая камера и управление:**
   - FOV 38° под углом 45° с плавной интерполяцией следования за игроком.
   - Управление WASD с автоматической конвертацией в изометрическую плоскость.
   - 3D Raycasting от курсора мыши: подсветка слотов полок и коробок.

## 🚀 Быстрый старт

### Требования
- Node.js >= 20.x
- npm >= 10.x

### 1. Установка зависимостей
В корне проекта выполните:
```bash
npm install
```

### 2. Запуск в режиме разработки

Для запуска сервера и клиента одновременно:
```bash
# В терминале 1: запуск сервера (порт 8080)
npm run dev:server

# В терминале 2: запуск клиента (порт 3000)
npm run dev:client
```

Откройте в браузере: **`http://localhost:3000`**

### 3. Сборка для Production
```bash
npm run build
```

## 🎮 Управление в игре

| Клавиша / Кнопка | Действие |
| :--- | :--- |
| **W, A, S, D** / Стрелки | Перемещение персонажа в изометрии |
| **Shift** | Ускорение (бег) |
| **Мышь (наведение)** | Прицеливание курсором на коробки и слоты полок |
| **E** | Поднять коробку с пола / Поставить коробку |
| **R** или **Пробел** | Открыть запечатанную коробку |
| **G** | Бросить коробку на пол |
| **ЛКМ (левая кнопка)** | Выставить товар из открытой коробки на выбранный слот полки |
| **ПКМ (правая кнопка)** | Забрать товар со слота полки обратно в коробку |
| **Кнопка «🚚 Заказ поставки»** | Заказать коробки с товарами у поставщика в зону разгрузки |
| **Кнопка «🚪 Сменить комнату»** | Создать или войти в кооперативную сессию другого магазина |

│   │   ├── index.html
│   │   └── vite.config.ts

│   ├── server/                  # Авторитативный игровой сервер (Node.js + ws)

│   │   │   ├── rooms/           # StoreRoom: тикрейт 25Hz, авторитативная валидация

│   │   └── package.json
│   │
