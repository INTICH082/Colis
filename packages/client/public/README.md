# Runtime Game Assets (Игровые ассеты)

Все файлы из этой папки раздаются клиенту напрямую через Vite / Game Server и доступны по абсолютным путям.

## Рекомендуемая структура:

### 1. `models/` (3D модели)
Формат: **`.glb`** (или `.gltf`)
- **`characters/`** — модели персонажей, работников, покупателей и их анимации (`/models/characters/...`).
- **`furniture/`** — стеллажи, полки, кассовые зоны, тележки, холодильники (`/models/furniture/...`).
- **`boxes/`** — упаковочные коробки, ящики, паллеты (`/models/boxes/...`).
- **`products/`** — отдельные товары (банки, бутылки, пачки) (`/models/products/...`).
- **`environment/`** — архитектурные элементы (стены, окна, двери, светильники) (`/models/environment/...`).

### 2. `textures/` (Текстуры)
Формат: **`.png`**, **`.jpg`**, **`.webp`**
- **`floor/`** — текстуры пола магазина (diffuse, normal, roughness).
- **`walls/`** — текстуры стен, плитки, витрин.
- **`products/`** — развёртки этикеток, коробок и брендов.
- **`props/`** — текстуры металла, дерева, стекла.

### 3. `audio/` (Звуки и музыка)
Формат: **`.mp3`**, **`.ogg`**, **`.webm`**
- **`sfx/`** — звуки действий (взять/поставить коробку, открыть ленту, сканирование на кассе, шаги).
- **`ambient/`** — фоновый гул магазина, работа холодильников, освещения.
- **`music/`** — фоновые музыкальные треки супермаркета.

### 4. `ui/` (Интерфейс)
- **`icons/`** — иконки товаров, валюты, кнопок и статусов.
- **`fonts/`** — веб-шрифты (`.woff2`, `.ttf`).
