# 📥 Assets Inbox (Личный ящик для входящих ассетов)

Сюда можно просто перетаскивать или скачивать любые ассеты:
- 3D модели (`.glb`, `.gltf`, `.blend`, `.fbx`, `.obj`, `.bbmodel`)
- Текстуры и изображения (`.png`, `.jpg`, `.webp`, `.svg`, `.psd`)
- Звуки и музыку (`.mp3`, `.wav`, `.ogg`)
- Архивы (`.zip`)

## ⚙️ Как это работает:
1. Вы скидываете сюда файлы в любом виде.
2. Файлы внутри этой папки **НИКОГДА не попадут в Git** (они занесены в `.gitignore`) и не будут удалены гитом при пуллах.
3. Просто напишите мне в чат:
   > *"Рассортируй ассеты из инбокса"* или *"Подключи модель полки из инбокса"*
4. Я сам:
   - Определю назначение каждого файла.
   - Перенесу в нужную подпапку (`packages/client/public/...` или `assets_raw/...`).
   - При необходимости подключу в код игры.
