# Raw Assets & Source Files (Исходники ассетов)

В этой папке хранятся исходные файлы моделей, текстур и звуков для работы в графических и звуковых редакторах.

## Структура:
- **`blender/`** — проекты `.blend` для Blender (персонажи, стеллажи, торговый зал, пропсы).
- **`blockbench/`** — проекты `.bbmodel` для Blockbench (низкополигональные модели, воксели, анимации).
- **`textures_src/`** — исходники текстур и графики высокого разрешения (`.psd`, `.svg`, `.afphoto`, `.kra`).
- **`audio_src/`** — несжатые звуковые файлы (`.wav`, `.flac`) для последующей конвертации в web-форматы.
- **`references/`** — референсы, концепт-арты, палитры и идеи для супермаркета.

> **Примечание:** Экспортированные файлы для работы игры (в формате `.glb`, `.png`, `.webp`, `.mp3`) помещайте в папку `packages/client/public/`.
